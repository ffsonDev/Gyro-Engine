# 🎮 Gyro Engine

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Godot](https://img.shields.io/badge/Godot-4.7-478CBF?logo=godot-engine&logoColor=white)](https://godotengine.org)
[![Platform](https://img.shields.io/badge/Platform-Android-brightgreen)](https://www.android.com)

Gyro Engine — визуальный игровой движок, построенный на базе [Godot 4.7](https://godotengine.org), который позволяет создавать 2D-игры без написания кода. Собирайте игровую логику из цветных блоков, как конструктор, и собирайте APK прямо на телефоне.

## Возможности

### Визуальное программирование
- Сборка логики из блоков: События → Условия → Действия
- Редактор блоков с перетаскиванием (Drag & Drop)
- Поддержка Undo / Redo
- Сворачиваемые блоки для удобной организации

### Геймплей
- Физика: гравитация, коллизии, твёрдые тела, сенсоры, перетаскивание
- Камера: следование за объектом, параллакс-фоны, плавное слежение
- Частицы: пресеты — снег, дождь, огонь, искры, конфетти
- Звук: воспроизведение звуков и музыки (MP3, OGG, WAV), зацикливание
- Анимации: анимации спрайтов (spritesheets), твины (плавные анимации)
- Таймеры: одноразовые и повторяющиеся таймеры

### Объекты и графика
- Создание объектов: прямоугольники, текст, спрайты, круги, линии, спрайтовые анимации
- Градиенты, границы, скругление углов
- Слои (z-index)
- Теги и группы для массовых операций
- Якоря для адаптивного позиционирования на разных экранах

### Логика и данные
- Переменные: число, текст, булево, таблица (словарь/массив)
- Условия: всегда, переменная равна/больше, данные события равны/больше
- Циклы: повторить N раз, цикл от-до, для каждого в таблице
- Выражения: математика, сравнение, логические операторы, встроенные функции

### Виджеты
- Поля ввода текста
- Слайдеры
- Переключатели (чекбоксы)

### Мобильные возможности
- Сборка APK прямо на телефоне
- Сборка с подписью keystore
- Ориентация экрана (портрет / ландшафт / авто)
- Частичная поддержка мультитач
- События нажатия и касания экрана

### Данные и связь
- Сохранение/загрузка значений
- Чтение/запись файлов
- HTTP-запросы
- События HTTP-ответов

### Управление проектами
- Импорт / экспорт проектов (.gyroproj)
- Автосохранение с настраиваемым интервалом
- Система бэкапов (до 3 бэкапов)
- Встроенная документация

### Локализация
- Русский и английский языки
- Простое добавление новых языков

## Быстрый старт

### Запуск движка
1. Скачайте [Godot Engine 4.7](https://godotengine.org/download)
2. Клонируйте репозиторий:
   git clone https://github.com/YOUR_USERNAME/gyro-engine.git
3. Откройте папку проекта в Godot Engine
4. Нажмите F5 для запуска

### Сборка APK
1. Настройте настройки проекта (имя приложения, имя пакета, иконка)
2. Создайте или импортируйте keystore (.p12)
3. Нажмите «Собрать APK»
4. Выберите место сохранения

### Создание первой игры
1. Нажмите + в Менеджере проектов → введите имя → Создать
2. Откройте хаб проекта → Структура → + → Скрипт → назовите "Main"
3. Откройте скрипт → + → События → При старте
4. Внутри события → + → Объекты → Создать объект
5. Нажмите ▶ для запуска!

## Документация

Движок включает подробную встроенную документацию, охватывающую:
- Введение и быстрый старт
- События, условия, действия
- Физику, камеру, частицы, звук
- Объекты, виджеты, переменные
- Сборку APK, файловые операции
- Часто задаваемые вопросы и советы по отладке

Доступ через кнопку «Документация» на главном экране.
